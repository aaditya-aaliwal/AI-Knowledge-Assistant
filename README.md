# AI Knowledge Assistant

An AI Backend project built step by step while learning modern backend development and Generative AI concepts.

## 🎯 Project Goal

The goal of this project is to build a production-style AI Backend from scratch while learning each concept and integrating it into a single application.

Every concept is:
- Learned theoretically
- Understood from an interview perspective
- Implemented into the same project
- Tested and verified before moving to the next phase
